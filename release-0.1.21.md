Celý archiv povolených kanálů přes YouTube Data API: 50 položek na stránku a tlačítko Načíst další. Klíč se nastavuje v rodičovské správě. Bez klíče zůstává seznam novinek.

Rychlejší návrat do galerie se zachováním načtených stránek, paměťová cache náhledů a seznamů, opakované použití přehrávače. Přidána obsluha chyb a opakování načtení.

Návod: https://github.com/petan86/bezpecne-video-tv/blob/main/ARCHIV_KANALU.md

Ověřeno sestavení APK. Načítání s uživatelským API klíčem a chování na Chromecastu vyžaduje ověření na zařízení. Vložený přehrávač dál řídí kvalitu a buffer sám.
